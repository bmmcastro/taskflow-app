Autor: Bruno Castro

1. A app

Objetivo. Uma app Android em Kotlin para gerir projetos e tarefas em equipa, estilo Trello. É o cliente móvel do TaskFlow (projeto web da UC00605, em produção em https://taskflow.algarit.pt): a app consome a API REST do site, por isso uma tarefa movida no telemóvel aparece logo no site e vice-versa.

Público-alvo. Pequenas equipas com trabalho partilhado: trabalhos de escola, projetos de curso, pequenas empresas.

Porque este tema. As sugestões do enunciado usavam APIs públicas de demonstração; escolhi a API real do TaskFlow porque a conheço bem (fiz o recurso Tarefas no projeto web), tem casos reais (autenticação, validações, erros de negócio) e o resultado é útil de verdade.

API. REST, JSON, HTTPS. Autenticação por id do utilizador (a mesma que o site usa no browser). Conta de demonstração: demo@taskflow.pt / 1234.

4. Fluxo de navegação

Login → Projetos (home) → Quadro → Detalhe; do Quadro abrem-se Membros e Relatório; o Perfil abre dos Projetos; o Convite é ponto de entrada autónomo (Activity). Implementado num grafo de navegação com 8 destinos, argumentos por Safe Args, Toolbar ligada ao NavController e botão "voltar" do sistema sempre funcional.

RGPD: a app recolhe nome, email e palavra-passe (contas) e o conteúdo dos projetos — os mesmos dados do site, com o mesmo responsável (algarit.pt) e política de privacidade do site. No dispositivo guarda apenas o id/nome da sessão (SharedPreferences). Uma única permissão: INTERNET. allowBackup="false".
